# OrgTechApp — Материальный учёт оргтехники

Информационно-справочная система для учёта оргтехники, истории её движения,
закрепления техники за сотрудниками, обработки заявок и формирования отчётности.

Приложение реализовано на WPF (C#, .NET 10) с базой данных MS SQL Server.
В пояснительной записке также спроектирован REST API с JWT и Swagger.

## Возможности

- авторизация и разграничение прав по ролям `ADMIN`, `MANAGER`, `OPERATOR`, `AUDITOR`, `USER`;
- просмотр, поиск и фильтрация оргтехники;
- карточка оборудования с фотографией;
- добавление и редактирование оборудования;
- оформление операций: поступление, передача, списание, ремонт, инвентаризация;
- создание и обработка заявок;
- отчёты: наличие по подразделениям, списанная техника, история операций;
- управление пользователями и ролями для администратора.

## Требования

- Windows 10 или Windows 11;
- .NET Desktop Runtime 10;
- доступ к серверу MS SQL Server;
- Visual Studio 2022/2026 или .NET SDK для сборки.

## База данных

В папке `database` находятся скрипты:

- `schema.sql` — создание таблиц, ограничений, представлений и хранимых процедур;
- `data.sql` — тестовые данные.

Порядок выполнения:

1. `schema.sql`;
2. `data.sql`.

Строка подключения задаётся в `Db.cs`. Перед публикацией в открытом репозитории
рекомендуется заменить логин и пароль учебной базы на свои и не хранить пароли
в исходном коде.

## Сборка и запуск

```powershell
dotnet build OrgTechApp.csproj -c Release
```

Запуск:

- `Запуск.bat`;
- или `bin\Release\net10.0-windows\OrgTechApp.exe`.

## Структура проекта

- `*.xaml`, `*.xaml.cs` — окна WPF;
- `Db.cs` — параметризованные запросы к MS SQL Server;
- `PasswordHelper.cs` — хеширование паролей с солью;
- `Session.cs` — текущая сессия и проверка прав;
- `PhotoHelper.cs` — работа с фотографиями оборудования;
- `Assets/Images` — изображения интерфейса;
- `database` — SQL-скрипты.
